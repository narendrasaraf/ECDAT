# Offline replay acceptance

Verified 2026-09-25. `scripts/replay.py` restores exported public bytes into a fresh temporary folder, invokes the scanner in a separate process with fresh state and no server connection, and compares each historical scan independently. It compares findings, coverage (including failures and unsupported inputs), evidence excerpts and provenance, and the exact finding-to-evidence relationships. Database-generated IDs are excluded from content comparisons. Snapshot bytes, paths, canonical digest, official CBOM schema/inventory, audit checkpoint, proposal digest, reviewer separation and exported baseline scan digest are also checked.

Sixteen regression cases pass: actual fresh scanner reproduction, resealed finding/evidence/coverage/citation mutations, missing bytes, seven cross-platform unsafe path classes, trusted-digest truncation detection, baseline tampering, and export record-limit rejection. Exports include raw baseline scan records and refuse to silently truncate beyond 10,000 records per kind.

The retained acceptance bundle at `.ecdat/acceptance/runs/20260924T173341Z-e8fcde45/bundle.json` has independently supplied canonical digest `d131ca72f143d57bf202c86dcd273b3fd5c0db766a59f83dcb8a4e08e512ace9`. Replay report is `.ecdat/acceptance/replay-report.json`. All four historical scans reproduce findings (8, 8, 8, 9) and coverage. Three reproduce exact evidence. The oldest scan fails exact evidence reproduction because the certificate parser excerpt changed from “X.509 public-key metadata” to “Public-key metadata” without a version increment. This is surfaced as a failure, not normalized away. Old bundles also lack exported baseline scan records.

A new current-version scan/export is necessary for a clean baseline provenance demonstration. Historical records must remain untouched. Scanner behavioral changes must increment the parser version going forward.

Offline replay deliberately reports unavailable rather than claiming fresh original authenticated TLS results (the private key is withheld), Syft execution (requires isolated runtime), or current blockchain state (use the independent passport verifier). Missing/withheld artifact bytes likewise prevent complete reproduction. Exit status is 0 for successful integrity/static replay, 2 for partial replay, and 1 for failure. A locally supplied digest must come from an independently trusted receipt; a digest read from the same bundle only detects accidental corruption.
